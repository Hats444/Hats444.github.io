# Hats444 — Portfolio

Site pessoal hospedado no **GitHub Pages**.

## URL

Após publicar: **https://hats444.github.io**

## Estrutura

```
├── index.html      # Página principal
├── css/style.css   # Estilos
├── js/main.js      # Interações (menu, scroll reveal)
└── README.md
```

## Publicar / atualizar

```bash
git add .
git commit -m "Atualiza portfolio"
git push origin main
```

GitHub Pages → Settings → Pages → **Deploy from branch: main / root**.

## Personalizar

- Nome e bio: `index.html` seção `#sobre`
- Projetos: seção `#projetos`
- Links de contato: seção `#contato` (adicione e-mail, LinkedIn, Telegram)
